# FinTrack AI

## 📌 Project Overview

FinTrack AI is a smart personal finance dashboard designed to help users track expenses, monitor budgets, analyze spending behavior, and gain financial insights through interactive visualizations.

The project combines financial analytics and dashboard reporting to provide a better understanding of personal financial performance.

---

## 🎯 Objectives

- Track income and expenses
- Analyze spending habits
- Monitor savings goals
- Visualize financial trends
- Support data-driven financial decisions
